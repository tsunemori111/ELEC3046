## 0. 考试重点地图

从课堂板书看，期末重点不是单纯背器件，而是围绕“点对点光链路如何建模、如何算性能”展开：

2. 光纤链路：损耗、色散、PMD、色散补偿、WDM/PON/ROADM/EDFA 的系统作用。
3. 发射端与调制：LED/LD、MZM、OOK、BPSK/QPSK/QAM、星座图、频谱效率和噪声容忍度。
4. 接收端：PIN/APD、直接检测、相干检测、90 度混合器、平衡探测、偏振分集。
5. 噪声与性能：热噪声、散粒噪声、ASE、信号-ASE 拍频、ASE-ASE 拍频、SNR、OSNR。
6. 误码率与灵敏度：OOK BER、Q 因子、QPSK/16QAM BER、量子极限、接收机灵敏度、灵敏度代价。
7. DSP：色散均衡、2x2 MIMO 蝶形均衡、CMA/RDE、载波恢复、时钟恢复。

## 1. 基础量与单位

### 1.1 波长、频率和光子能量

- 真空中 `c = 3e8 m/s`。
- `f = c / lambda`，角频率 `omega = 2 pi f`。
- 光子能量 `E = h nu = h c / lambda`。
- 在 1550 nm 附近，单个光子能量约为 `1.28e-19 J`。

常考点：

- 频率带宽和波长带宽互换：  
  `Delta f = c Delta lambda / lambda^2`，或 `Delta lambda = lambda^2 Delta f / c`。
- 0.1 nm OSNR 参考带宽在 1550 nm 附近约等于 12.5 GHz。

### 1.2 dB 和 dBm

- 功率比：`G(dB) = 10 log10(P2/P1)`。
- dBm：`P(dBm) = 10 log10(P(mW))`。
- 链路功率常用加减法：  
  `Pout(dBm) = Pin(dBm) + Gain(dB) - Loss(dB)`。

常用换算：

- 0 dBm = 1 mW。
- 10 dBm = 10 mW。
- -10 dBm = 0.1 mW。
- 光纤损耗 `alpha = 0.2 dB/km`，80 km 损耗约 16 dB。

### 1.3 比特率、码元率、频谱效率

- 比特率 `Rb`：每秒传输 bit 数。
- 码元率 `Rs`：每秒传输符号数，单位 Baud。
- 每码元 bit 数：`log2 M`。
- 对 M-QAM：`Rb = Rs log2 M`，双偏振再乘 2。
- 频谱效率提高通常以噪声容忍度下降为代价：QPSK 比 OOK 频谱效率高，16QAM 更高，但对 OSNR 要求更苛刻。

## 2. 光通信系统总体框架

点对点光链路可以分为：

- 发射端 Tx：比特流、编码、调制、DAC/驱动器、激光器、MZM/IQ 调制器。
- 信道：光纤损耗、色散、PMD、非线性、EDFA/ROADM/WDM。
- 接收端 Rx：光电探测、TIA/ADC、DSP、判决、解码。

应用场景：

- 接入网 Access：距离短、成本敏感，典型如 PON。
- 城域网 Metro：城市范围，多节点、多波长。
- 骨干网 Core：长距大容量，常用相干检测、EDFA、ROADM、DSP。
- 数据中心互联 DCI：高速、低功耗、短中距。

## 3. 光纤波导与传输损伤

### 3.1 数值孔径与单模条件

阶跃折射率光纤：

- 相对折射率差：`Delta = (n1 - n2) / n1 ≈ (n1^2 - n2^2)/(2 n1^2)`。
- 数值孔径：`NA = sqrt(n1^2 - n2^2) ≈ n1 sqrt(2 Delta)`。
- 归一化频率：`V = 2 pi a NA / lambda`。
- 单模条件：`V < 2.405`。

典型题型：给 `n1, n2, lambda`，求单模最大芯半径 `a_max = 2.405 lambda / (2 pi NA)`。

### 3.2 损耗

主要损耗机制：

- 吸收损耗。
- 瑞利散射。
- 光纤不均匀、微弯、宏弯。
- 接续、连接器、耦合损耗。

链路预算的基本式：

`Prx(dBm) = Ptx(dBm) - alpha L - L_connector - L_splice + G_amp - Margin`

接收功率必须高于接收机灵敏度，否则 BER 不满足要求。

### 3.3 色散

色散导致不同频率或模式的光到达时间不同，引起脉冲展宽和码间串扰。

主要类型：

- 模式色散：多模光纤中不同模式路径不同。阶跃多模光纤中往往占主导。
- 材料色散：材料折射率随波长变化。
- 波导色散：模式能量在芯/包层分布随波长变化。
- PMD：双折射导致两个正交偏振群速度不同，随机时变。

单模光纤常用色散公式：

- `Delta T = D L Delta lambda`。
- 等价形式：`Delta T = 2 pi beta2 L Delta f`。
- `D = -(2 pi c / lambda^2) beta2`。

工程理解：

- 1310 nm 附近常规单模光纤色散接近零。
- 1550 nm 附近损耗最低，但普通 SMF 色散约 17 ps/(nm km)。
- 色散位移光纤把零色散点移到 1550 nm，但 DWDM 中会增强四波混频 FWM，因此工程中常用非零色散位移光纤。
- DCF 可用相反符号色散补偿，但有额外损耗；相干系统中常在 DSP 中做数字色散补偿。

### 3.4 PMD

PMD 来源于光纤双折射。两个正交偏振的有效折射率或群速度不同，会产生：

- 相位差变化：偏振态周期性演化，相关概念是拍长。
- 差分群时延 DGD：两个偏振分量到达时间不同，造成脉冲展宽。

PMD 是随机时变损伤，常通过相干接收机中的 2x2 MIMO 自适应均衡补偿。

## 4. 光源、调制器与光放大器

### 4.1 LED 与 LD

LED：

- 自发辐射为主。
- 谱宽较宽，调制带宽较低。
- 成本低，适合短距、低速或多模场景。

LD：

- 受激辐射为主，有阈值电流。
- 谱宽窄、功率高、调制带宽高。
- 相干系统中关注线宽和相位噪声。

激光器阈值的物理图像：谐振腔内往返一次后，增益要补偿镜面损耗和内部损耗，才能形成稳定振荡。

### 4.2 MZM 与 IQ 调制

MZM 利用电光效应改变两臂相位差，通过干涉把电信号映射到光强或光场。

常考理解：

- OOK/IM-DD：主要调制光强，接收端直接检测。
- 相干 IQ 调制：分别控制 I/Q 两个正交分量，能产生 QPSK、16QAM 等星座。
- MZM 偏置点会影响线性度、消光比和啁啾。

### 4.3 EDFA 与 ASE

EDFA 通过掺铒光纤实现 C/L 波段光放大。系统作用：

- 补偿跨段光纤损耗。
- 支持 WDM 多波长同时放大。
- 引入 ASE 噪声，限制 OSNR。

噪声系数：

- `F = (SNR_in)/(SNR_out)`。
- `F_dB = 10 log10 F`。
- 高增益 EDFA 中，常近似 `F ≈ 2 n_sp`。

ASE 噪声：

- 单偏振 ASE 功率谱密度常写作 `S_ASE = n_sp h nu (G - 1)`。
- 两个偏振合计噪声功率常写作 `P_ASE = 2 n_sp h nu (G - 1) B_o`。
- `OSNR = P_signal / P_ASE`，通常指定参考带宽 `B_ref = 0.1 nm`。

多跨段 OSNR：

- 每一跨 EDFA 都会加入 ASE。
- 若每跨损耗由放大器恰好补偿，跨段数 `Ns` 增加时，ASE 近似线性累积，OSNR 下降。
- 分贝域常见趋势：跨段数增加 10 倍，OSNR 约下降 10 dB。

OSNR 与电信号 SNR：

- 对相干系统，课件给出双偏振关系：  
  `SNR = (B_ref / Rs) OSNR`。
- 因此同样 OSNR 下，码元率越高，等效 SNR 越低。

## 5. 光检测与接收机

### 5.1 光电探测器关键参数

响应度：

`Rd = I_p / P = eta q / (h nu) = eta q lambda / (h c)`

常用近似：

`Rd(A/W) ≈ eta lambda(um) / 1.24`

其他参数：

- 谱响应：有效工作波长范围。
- 响应速度：`f_3dB ≈ 0.35 / t_r`。
- RC 限制：`t_r = 2.19 R_L C_d`，`f_3dB ≈ 1/(2 pi R_L C_d)`。
- 暗电流：无光时仍存在的电流，会贡献散粒噪声。

### 5.2 PIN vs APD

PIN：

- 结构简单，噪声较低，无内部增益。
- 常用于中高功率、低成本接收。

APD：

- 雪崩倍增，内部增益 `M`。
- 微弱信号下可提高 SNR。
- 但倍增过程随机，会产生过剩噪声因子 `F_A(M)`。
- 存在最优增益 `M_opt`：增益太小热噪声主导，增益太大过剩噪声变重。

APD 噪声趋势：

`sigma_s^2 = 2 q M^2 F_A Rd P_in Delta f`

### 5.3 直接检测与相干检测

直接检测：

- 探测光强，电流 `I ∝ |E|^2`。
- OOK/IM-DD 常用。
- 接收端简单，但丢失光场相位信息。

相干检测：

- 接收信号与本振 LO 混频。
- 可恢复光场幅度、相位、偏振信息。
- 典型结构：90 度光混合器、平衡探测器、偏振分集、ADC、DSP。
- 可支持 QPSK/QAM、CD/PMD 补偿、载波恢复和时钟恢复。

## 6. 噪声、SNR、OSNR

### 6.1 噪声来源

发端：

- 激光相位噪声。
- 激光强度噪声 RIN。
- DAC 量化噪声。
- 驱动放大器电噪声。

链路：

- EDFA ASE。
- 非线性噪声，如 FWM。
- 反射噪声和 MPI。
- 多模光纤模态噪声。

收端：

- 热噪声。
- 散粒噪声。
- 暗电流噪声。
- 信号-ASE 拍频噪声。
- ASE-ASE 拍频噪声。
- TIA/低噪声电放大器噪声。

### 6.2 散粒噪声

光电流平均值：

`I_p = Rd P = eta q P / (h nu)`

散粒噪声方差：

`sigma_s^2 = 2 q (I_p + I_d) Delta f`

散粒噪声是白噪声，来源于光子到达和电子-空穴对产生的量子随机性。

散粒噪声主导时：

`SNR = eta P_in / (2 h nu Delta f)`

若 `Delta f = B/2`，且一比特平均光子数为 `Np`：

`SNR = eta Np`

### 6.3 热噪声

热噪声来自电阻中载流子热运动。常用电流噪声方差：

`sigma_T^2 = 4 k_B T Delta f / R_L`

热噪声主导时：

- 信号电流 `I ∝ P`。
- 噪声近似与光功率无关。
- 所以 `SNR ∝ P^2`。

散粒噪声主导时：

- 噪声方差 `∝ P`。
- 所以 `SNR ∝ P`。

这是接收机灵敏度推导中常考的比例关系。

## 7. 调制格式与误码率

### 7.1 OOK 直接检测

OOK 中，“1”和“0”的采样电平分别近似服从高斯分布，均值为 `I1, I0`，标准差为 `sigma1, sigma0`。

Q 因子：

`Q = (I1 - I0)/(sigma1 + sigma0)`

最佳判决门限近似满足：

`(I_D - I0)/sigma0 = (I1 - I_D)/sigma1 = Q`

BER：

`BER = 1/2 erfc(Q / sqrt(2))`

记忆点：

- `BER < 1e-9` 需要 `Q > 6`。
- `BER < 1e-12` 需要 `Q > 7`。

热噪声主导、0 码无光、两电平方差相同时：

`Q = I1 / (2 sigma_T)`

### 7.2 QPSK 与 16QAM

相干系统通常用 `E_s/N0` 或 `E_b/N0` 描述误码。

QPSK：

- 每个码元 2 bit。
- 课件给出近似：`BER ≈ 1/2 erfc(sqrt(E_b/N0))`。
- 格雷映射时，BER 约为 SER 的一半。

16QAM：

- 每个码元 4 bit。
- 星座点更密，频谱效率更高，但要求更高 OSNR。
- 课件给出近似：`BER ≈ 3/8 erfc(sqrt(2 E_avg/(5 N0)))`。

板书强调的判断：

- OOK 题多从高斯电平分布、Q 因子、接收灵敏度入手。
- QPSK/QAM 题多从星座图、`E_s/N0`、OSNR 入手。
- 相干检测不需要区分 1 码/0 码噪声，而是看码元平均能量与噪声谱密度。

## 8. 接收机灵敏度

### 8.1 定义

接收机灵敏度：在指定 BER 下，接收端所需的最小平均光功率。

OOK 理想消光比时，0 码功率为 0，若 1 码平均光子数为 `Np`：

`P_rec = Np h nu B / 2`

其中 `B` 为比特率，除以 2 是因为平均功率按 1/0 等概率平均。

### 8.2 量子极限

理想接收机只考虑量子起伏，无热噪声、暗电流和 ASE。

若 1 码平均光子数为 `Np`，产生 `m` 个电子-空穴对的概率服从泊松分布：

`P(m) = exp(-Np) Np^m / m!`

0 码无光，不会误判为 1；1 码只有在没有产生电子-空穴对时才误判为 0：

`BER = exp(-Np)/2`

因此：

- `BER < 1e-9` 时，1 码平均光子数约需 `Np > 20`。
- 按平均每比特光子数计，约为 `> 10 photons/bit`。

课件还提醒：用高斯近似散粒噪声时，`eta = 1` 且 `Np = 36` 对应 `BER = 1e-9`；真实量子极限应使用泊松统计。

### 8.3 PIN/APD 直接检测灵敏度

热噪声主导：

- `P_rec ∝ Q sqrt(B)`。
- 与 NEP 成正比，NEP 本身与带宽平方根相关。

散粒噪声主导：

- `P_rec ∝ Q^2 B`。
- 也就是更高速率需要线性提高功率。

APD 的作用：

- 内部增益能放大信号电流，使热噪声相对不那么重要。
- 但 APD 引入过剩噪声，所以存在最优增益。

### 8.4 直接检测 + 光预放

光预放接收机中，主要噪声是 ASE 拍频：

- 信号-ASE 拍频。
- ASE-ASE 拍频。

课堂例题公式可写为：

`Np = (F_n/2) [ Q^2 + Q sqrt(r_o - 1/2) ]`

其中：

- `F_n` 为光放大器噪声指数。
- `r_o = Delta nu_o / Delta f`，光滤波器带宽与电滤波器带宽之比。
- `Q` 由 BER 指标决定。

结论：

- `F_n` 越小，灵敏度越好。
- 光滤波器越窄，`r_o` 越小，灵敏度越好，但不能窄到削弱信号。

### 8.5 相干检测灵敏度与 OSNR

QPSK：

- 若 `BER = 1e-3`，课件给出 `E_s/N0 > 9.5`。
- 28 GBd、`B_ref = 12.5 GHz` 时：  
  `OSNR_min(dB) = 10 log10(9.5) + 10 log10(28/12.5) ≈ 13.2 dB`。

16QAM：

- 若 `BER = 1e-3`，课件给出对应要求更高。
- 28 GBd 时：  
  `OSNR_min ≈ 20 dB`。

记忆点：同样速率和 BER 下，16QAM 的 OSNR 要求显著高于 QPSK。

### 8.6 灵敏度代价

灵敏度代价是实际系统相对理想系统需要额外增加的功率，常以 dB 表示。

常见来源：

- 有限消光比：0 码不再是 0，眼图闭合。
- 强度噪声 RIN。
- 时钟抖动：采样点偏离最佳位置。
- 色散和 PMD 残余。
- 滤波器带宽不匹配。

## 9. DSP 复习重点

### 9.1 相干接收机 DSP 流程

典型流程：

1. ADC 采样。
2. 重采样/时钟恢复。
3. 色散补偿。
4. 2x2 MIMO 自适应均衡，补 PMD 和偏振旋转。
5. 频偏估计。
6. 相位恢复。
7. 判决和解映射。

### 9.2 色散补偿

CD 是静态线性损伤，常用频域补偿降低复杂度。

色散展宽：

`Delta T = D L Delta lambda = 2 pi beta2 L Delta f`

色散导致的脉冲展宽可跨几百甚至几千个码元周期，因此长距相干系统中 CD 补偿是 DSP 的基础模块。

频域补偿思想：

- 光纤色散是线性系统，有频率响应 `H_CD(f)`。
- 接收端乘以逆响应或共轭响应进行补偿。

### 9.3 自适应均衡

离散信道模型：

`x[k] = h[k] * s[k] + eta[k]`

均衡器输出：

`y[k] = w^H x[k]`

迫零 ZF：

- 目标 `c[k] = h[k] * w*[k] = alpha delta[k-d]`。
- 缺点：忽略噪声，可能放大噪声，实际系统较少直接使用。

MMSE/LMS：

- 目标最小化 `E{|s[k] - y[k]|^2}`。
- LMS 更新：`w[k] = w[k-1] + mu x[k] e*[k]`。
- `mu` 太大收敛快但误差大，太小收敛慢。

偏振复用系统：

- 用 2x2 MIMO 蝶形均衡器处理 H/V 两个偏振。
- 输出 `y1, y2` 是两个解复用后的偏振通道。

盲均衡：

- CMA：适用于恒模信号，如 QPSK。
- RDE：适用于多半径 QAM，如 16QAM，因为 QAM 不是恒模星座。

### 9.4 载波恢复

相干系统中主要相位问题：

- 载波频率偏移：发射激光器和本振激光器频率不完全相同。
- 相位噪声：激光器线宽导致相位随机游走。

信号模型：

`y[k] = s[k] exp{j(theta[k] + 2 pi Delta f k T_s)} + eta[k]`

QPSK 频偏估计常用四次方方法：

1. 将 `y[k]` 提到 4 次方，消除 QPSK 调制信息。
2. 对 `(y[k])^4` 做 FFT，找峰值频率。
3. 峰值频率除以 4 得到 `Delta f`。
4. 乘反向旋转因子补偿频偏。

相位噪声：

`theta[k] = theta[k-1] + Delta theta[k]`

`var(Delta theta) = 2 pi Delta nu T_s`

所以激光线宽越大、码元周期越长，相位噪声越严重。

常用算法：

- Viterbi & Viterbi：适合 M-PSK，用 M 次方去调制，再估相位。
- Decision-Directed：用判决符号辅助估相位，适用于高 OSNR、判决可靠时。

### 9.5 时钟恢复

时钟误差包括：

- 采样相位误差。
- 采样频率误差。

时钟恢复结构：

- 插值器：从邻近采样点估计最佳采样时刻。
- TED：Timing Error Detector，生成时钟误差信号。
- Loop Filter：环路滤波器，常用 PI。
- NCO：数字控制振荡器，更新采样位置。

常见 TED：

- Gardner TED：经典，适合 NRZ/RZ。
- Modified Gardner：适合小滚降奈奎斯特脉冲。
- Godard TED：可在频域实现，适合和 FFT/IFFT DSP 链结合。

## 10. 经典例题

### 例题 1：dBm 与链路损耗

题：发射功率 `0 dBm`，光纤损耗 `0.2 dB/km`，长度 `80 km`，连接器和接续总损耗 `3 dB`，无放大器。求接收功率。

解：

`Prx = 0 - 0.2*80 - 3 = -19 dBm`

若接收机灵敏度为 `-18 dBm`，则功率不够；至少需要 1 dB 额外增益或减少损耗，实际还应留系统余量。

### 例题 2：单模光纤最大芯半径

题：`n1 = 1.465`，`n2 = 1.460`，`lambda = 1.25 um`，求单模最大芯半径。

解：

`NA = sqrt(n1^2 - n2^2) ≈ 0.121`

单模条件 `V < 2.405`：

`a_max = 2.405 lambda / (2 pi NA)`

代入：

`a_max ≈ 2.405*1.25/(2*pi*0.121) ≈ 3.96 um`

最大芯直径约 `7.9 um`。

### 例题 3：阶跃多模光纤模式色散

题：`n1 = 1.48`，`n2 = 1.46`。估算阶跃多模光纤单位长度模式展宽。

解：

`Delta = (n1 - n2)/n1 = (1.48 - 1.46)/1.48 ≈ 0.0135`

当 `n1 ≈ n2`：

`Delta tau / L ≈ n1 Delta / c`

代入：

`Delta tau/L ≈ 1.48*0.0135/(3e8) = 6.7e-11 s/m`

换算：

`Delta tau/L ≈ 67 ns/km`

结论：阶跃多模光纤模式色散很大，不适合长距高速。

### 例题 4：总展宽中分离模式色散

题：1 km 光纤测得总展宽 `20 ns`，材料色散贡献 `2.2 ns`，波导色散忽略。求模式色散。

解：

总展宽按平方和近似：

`Delta tau_total = sqrt(Delta tau_modal^2 + Delta tau_disp^2)`

所以：

`Delta tau_modal = sqrt(20^2 - 2.2^2) ns ≈ 19.9 ns`

结论：模式色散占主导。

### 例题 5：散粒噪声极限下的光子数

题：散粒噪声主导，量子效率 `eta = 1`，要求 `SNR = 20 dB`，求每比特光子数。

解：

`20 dB` 对应线性 SNR = 100。

散粒噪声主导且 `Delta f = B/2` 时：

`SNR = eta Np`

所以：

`Np = 100 photons/bit`

若在 `lambda = 1550 nm`、`B = 10 Gb/s` 下，对应 1 码功率约：

`P = Np h nu B ≈ 100 * 1.28e-19 * 1e10 = 128 nW`

### 例题 6：OOK 的 Q 因子与 BER

题：OOK 直接检测系统要求 `BER < 1e-9`，问 Q 因子大约要多大？

解：

`BER = 1/2 erfc(Q/sqrt(2))`

课件结论：

`BER < 1e-9` 时 `Q > 6`。

若题目给 `I1, I0, sigma1, sigma0`，先算：

`Q = (I1 - I0)/(sigma1 + sigma0)`

再判断 BER 是否满足。

### 例题 7：光预放 OOK 接收机灵敏度

题：`Q = 6`，光放大器噪声指数 `F_n = 2`，`r_o = Delta nu_o / Delta f = 2`，求最佳接收机灵敏度光子数。

解：

使用课堂公式：

`Np = (F_n/2) [ Q^2 + Q sqrt(r_o - 1/2) ]`

代入：

`Np = (2/2) [ 36 + 6 sqrt(1.5) ]`

`Np ≈ 43.3 photons/bit`

结论：降低放大器噪声指数、压窄合适的光滤波器带宽，都可以提高灵敏度。

### 例题 8：QPSK 的 OSNR 灵敏度

题：28 GBd QPSK，`BER = 1e-3` 时需要 `E_s/N0 = 9.5`，OSNR 参考带宽 `B_ref = 12.5 GHz`，求最小 OSNR。

解：

`OSNR = (E_s/N0) * (Rs/B_ref)`

分贝形式：

`OSNR(dB) = 10 log10(9.5) + 10 log10(28/12.5)`

`≈ 9.8 + 3.5 = 13.3 dB`

课件给出约 `13.2 dB`。

### 例题 9：16QAM 的 OSNR 灵敏度

题：28 GBd 16QAM，`BER = 1e-3`，课件给出等效要求 `E_avg/N0 > 11.2`，求 OSNR 数量级。

解：

课件公式：

`OSNR(dB) = 10 log10(4*11.2) + 10 log10(28/12.5)`

计算：

`10 log10(44.8) ≈ 16.5 dB`

`10 log10(28/12.5) ≈ 3.5 dB`

所以：

`OSNR_min ≈ 20 dB`

结论：16QAM 的 OSNR 要求明显高于 QPSK。

## 12. 最后复习建议

1. 先把单位题练熟：dBm、dB、波长频率、0.1 nm 到 12.5 GHz。
2. 再练光纤题：NA、V 数、损耗预算、色散展宽。
3. 然后练接收机题：响应度、热噪声、散粒噪声、Q 因子、BER。
4. 最后练系统性能题：EDFA ASE、OSNR、多跨段、QPSK/16QAM OSNR 灵敏度。
5. 概念题重点背：PIN vs APD、DD vs coherent、OOK vs QAM、CD vs PMD、CMA vs RDE、频偏 vs 相位噪声、时钟恢复各模块。

如果时间只够抓核心，优先掌握这条主线：

`光功率/光子数 -> 光电流 -> 噪声方差 -> SNR/Q -> BER -> 灵敏度/OSNR -> 链路预算`
